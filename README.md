# QA — Testes Web, Mobile e API

## Sobre o projeto

Projeto prático de Quality Assurance desenvolvido durante a formação na TripleTen, reunindo atividades de testes de aplicações Web, Mobile e APIs.

## Atividades realizadas

- Elaboração e execução de casos de teste;
- Criação de classes de equivalência e análise de valores-limite;
- Validação de funcionalidades de aplicações;
- Verificação de requisições e respostas de API;
- Comparação entre resultados esperados e resultados obtidos;
- Registo dos resultados dos testes;
- Identificação e documentação de defeitos no Jira.

## Áreas de teste

- Testes de aplicações Web;
- Testes de aplicações Mobile;
- Testes de API;
- Design de testes;
- Documentação de casos de teste;
- Gestão de defeitos.

## Ferramentas e conhecimentos

- Quality Assurance (QA)
- Testes Manuais e Funcionais
- Testes de API
- Classes de Equivalência
- Valores-Limite
- Jira

## Documentação

As planilhas com os casos de teste e os resultados serão disponibilizadas neste repositório.

## Objetivo

Demonstrar conhecimentos práticos de Quality Assurance, planeamento e execução de testes, análise de resultados e identificação de defeitos.
